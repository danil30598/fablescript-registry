# FableScript

FableScript — экспериментальный язык для обучения и небольших программ. Проект находится на самом раннем этапе: текущая версия проверяет архитектуру `файл → интерпретатор → вывод → интеграция с VS Code`. Окончательный синтаксис ещё не выбран.

## Что уже работает

- Файлы с расширением `.fable`.
- Команда `print(...)`, переменные, выражения, условия, функции, циклы, коллекции, классы и модули.
- Установка пакетов из настраиваемого интернет-реестра с проверкой SHA-256.
- Запуск программы из командной строки.
- Расширение VS Code с подсветкой, комментариями, скобками и командой запуска.
- Автодополнение ключевых слов, шаблонов и объявленных переменных.
- Понятные ошибки с именем файла, строкой и столбцом.

## Запуск из командной строки

Требуется Node.js 18 или новее.

```powershell
node .\runtime\cli.js run .\examples\hello.fable
```

## Запуск расширения

1. Откройте папку `vscode-extension` в VS Code.
2. Нажмите `F5` и выберите `VS Code Extension Development`.
3. В новом окне откройте файл `.fable`.
4. Выполните команду `FableScript: Run Current File` через палитру команд или нажмите кнопку запуска в правом верхнем углу редактора.

Для запуска из расширения Node.js устанавливать не требуется: интерпретатор работает внутри VS Code. Node.js нужен только для отдельного запуска из командной строки.

Готовый установочный файл можно собрать без npm:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\package-extension.ps1
```

После сборки выберите в VS Code `Extensions: Install from VSIX...` и укажите файл `build/fablescript-0.0.18.vsix`.

Запустить текущий файл также можно клавишей `F6`, через кнопку `Run FableScript` в строке состояния или по ссылке запуска над первой строкой кода.

## Локальные модули

Инструкция `import math` загружает файл `math.fable` из той же папки, что и запускаемый файл. Обращение к функциям, классам и переменным модуля выполняется через точку:

```fable
import math

print(math.add(2, 3))
print(math.PI)
```

Имена, начинающиеся с `_`, остаются внутренними для модуля. Пример находится в `examples/modules`.

Если файла рядом нет, интерпретатор ищет установленный пакет `fable_modules/math.fable` в папке проекта.

## Пакеты из интернета

Пакеты устанавливаются из публичного JSON-реестра. Его адрес уже встроен в FableScript, а при необходимости его можно заменить в `fable.json`:

```json
{
  "name": "my_project",
  "registry": "https://raw.githubusercontent.com/danil30598/fablescript-registry/main/frameworks/index.json"
}
```

Глобальную команду можно установить один раз:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\install-cli.ps1
```

После открытия нового PowerShell пакет устанавливается из любой папки:

```powershell
fable install greetings
```

Без `fable.json` пакет ставится глобально в `~/.fable/packages` и доступен всем программам. Внутри проекта с `fable.json` пакет ставится локально в `fable_modules`. Флаг `--local` принудительно устанавливает пакет в текущую папку.

Или выполнить в палитре команд VS Code `FableScript: Установить пакет`. Установщик сохранит исходник в `fable_modules`, а точную версию и контрольную сумму — в `fable.lock.json`. Формат реестра и тестовый пакет находятся в папке `registry`.

После `import ` редактор предлагает доступные модули, а после `module.` — экспортируемые функции, классы и переменные этого модуля.

Публичный репозиторий: [danil30598/fablescript-registry](https://github.com/danil30598/fablescript-registry). Исходники языка и расширение находятся в `language`, реестр пакетов и описание экосистемы — в `frameworks`. Тестовый пакет устанавливается командой `fable install greetings`, пример его использования находится в `examples/packages/main.fable`.

## Структура

- `runtime/` — независимое ядро и CLI.
- `vscode-extension/` — расширение редактора.
- `examples/` — проверяемые примеры.
- `PLAN.md` — план развития.

## Ограничения прототипа

Существующий синтаксис пока минимален. Поля класса объявляются как `var name`, конструктор записывается как `__init(name, age)`, текущий объект доступен через `self`, а экземпляр создаётся вызовом `Person("Alex", 18)`. Типы полей и параметров конструктора необязательны и считаются `any`. Для локальных модулей редактор пока не проверяет существование членов до запуска программы.
