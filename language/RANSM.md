# Формат RANS#M1

`RANS#M1` — версионированный контейнер FableScript для защищённых текстовых файлов. Это не новый криптографический алгоритм: контейнер использует стандартные `scrypt` и AES-256-GCM из `node:crypto`.

## Представление файла

Первая строка содержит точную сигнатуру:

```text
RANS#M1
```

Вторая строка содержит Base64 от UTF-8 JSON со следующими полями:

```json
{
  "version": 1,
  "cipher": "aes-256-gcm",
  "kdf": "scrypt",
  "salt": "base64",
  "iv": "base64",
  "tag": "base64",
  "data": "base64"
}
```

## Создание ключа

- Пароль: строка UTF-8 длиной не меньше 8 символов.
- Соль: 16 случайных байт из `crypto.randomBytes()`.
- `scrypt`: `N = 16384`, `r = 8`, `p = 1`.
- Результат: ключ длиной 32 байта для AES-256.

## Шифрование

- Алгоритм: AES-256-GCM.
- IV: 12 случайных байт из `crypto.randomBytes()`.
- Длина тега аутентификации: 16 байт.
- Дополнительные аутентифицируемые данные (AAD): UTF-8 строка `RANS#M1`.
- Исходный текст и расшифрованный результат кодируются как UTF-8.

Новая соль и новый IV создаются при каждой записи, поэтому одинаковые данные с одинаковым паролем дают разные файлы.

## Гарантии и ограничения

GCM проверяет целостность: неверный пароль, изменённый заголовок или повреждённый шифротекст приводят к ошибке и не возвращают частично расшифрованные данные. Пароль не сохраняется, поэтому восстановление файла после потери пароля невозможно.

Стойкость зависит от качества пароля. Формат допускает автономный перебор паролей, поэтому минимальная длина в 8 символов является только нижней границей, а не гарантией безопасности. Размер файла и сам факт использования RANS#M1 не скрываются.
